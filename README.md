# PrecenseReporter

## What is this
This was a final project during my technical base year at NTI Södertörn (TE4), where the task was to create some kind of website that used react

## Purpose of website
This website is a "precense reporter" that can make it easier for teachers and the like to take attendance during role-call or during emergencies like a fire alarm while sending the data to a database
